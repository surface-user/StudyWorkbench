# 知识点目录与关系

本契约供 M3-03b 后端实施使用。当前题目已有科目和文字标签，作答记录已有不可变确认版和追加注记。以下目录、关系及修订操作均为规划。例：一本书和一道题都可关联到「函数／极限」，用户将「极限」移到「分析基础」后，关联仍指向同一知识点，旧作答仍显示当时的标签。

## 目录与关联

- 每个学习空间独立维护目录。用户命名科目，在科目内创建知识点，可以将知识点放在另一个知识点之下。科目、知识点依稳定 ID 标识。修改名称或上级保留 ID。允许不同科目或不同上级使用相同名称；同级非空名称按去除首尾空白后的完整文本判重，保留大小写和 Unicode 文本，沿用题目短文本的 500 字符上限。
- 科目下的一个知识点只有一个上级，可以位于科目根部。移动前检查目标属于同一科目且有效；移到自身或其后代时整次拒绝。跨科目同名不产生映射。用户可显式建立「相关」关系或以自己的名称标明从一个知识点到另一个知识点的关系。同空间跨科目关系有效。「相关」为无向关系，交换端点仍是同一条；有向关系的端点顺序有意义。拒绝自关联及重复的活动关系。仅目录父子关系要求无环。
- 用户可以把同空间的有效资料节点或题目显式关联到知识点。记录资源节点 ID 或题目 ID，二者区分类型；历史作答已有的确认版 ID 继续引用原版本。接口先校验空间与目标类型，外空间 ID 和不存在的 ID 均返回 404。读取目录及关系只返回有权限的标识和摘要；访问正文仍走原资料或题目入口。

## 修订和移除

- 创建、改名、移动、建立和撤销关联均为一次事务。请求带幂等键；同一空间内重试同内容返回原回执，改用不同内容返回 409。修改已有对象需带预期修订号；过时返回 409，响应提示刷新。先识别同请求重试，再检查修订号。两次并发移动不得合成父子循环。
- 移除知识点或科目需显式确认。有活动子项时提示先转移或移除子项，保持现场。成功时保留墓碑和既有修订；普通列表隐藏已移除项，历史查看以原 ID 和当时名称显示。指向墓碑或后来移除的资料的关系显示为不可用，不能据其读取内容。撤销关系保留原修订。重建同名项产生新 ID，旧关系不自动转移。

## 既有学习数据

- 用户显式选择后可以据旧文本标签创建目录项并关联选中的题目。仅凭同名、改名或移动均不改写原题、原文件、已确认的版本、成绩或注记。
- 题库统计依据当前题目的科目与文本标签，同一题对同科目同标签贡献一次。作答的历史标签取作答时确认版；旧作答缺少版本时保留未知。记录页的有效标签继续按完整事件流计算，省略或 null 保留上次显式值，空数组表示清除。目录调整不改变复习间隔、错题或掌握判断。见 [学习事件投影](adr/0011-learning-record-projections.md)。
- 实施时从实际数据库版本追加迁移。升级旧库后目录初始为空。全库备份保留 ID、空间、修订、墓碑及关系；恢复到空数据目录时核同空间引用、目录层级无环及数据库完整性。非法关系使恢复在切换前失败，旧库和原备份保留。

## 自动验收

通过普通后端入口，以两个空间、两个同名科目和各自的同名知识点建立夹具。验证跨空间请求拒绝、同级重名、移动造成循环、同键重试、并发冲突和带子项移除。关联一份资料和一道已确认题，改名、移动、移除后分别回读关联及原题版本。用带旧作答和明确清空标签事件的数据库升级、重启并备份恢复；核对迁移前后的文件字节、历史作答、修订、关系及统计。单纯通过现有标签回归只覆盖兼容基线。
