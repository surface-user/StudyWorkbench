# QuestionFile v1

2026-10-26 R4。此格式独立于旧QuestionDocument v1和提取Markdown v1；新增格式不放宽旧JSON导入。实现源为question_files_format.py，编译内容的跨语言Schema为contracts/question-file-content-v1.schema.json。

## 权威内容与标识

一个UTF-8 Markdown保存一题，最多1MiB。首行为Markdown标题；后随study-workbench-question-v1围栏JSON头，包含format_version=1、question稳定ID/题型/来源/知识点/关系等元数据、option_ids、attachments、可选passage及扩展元数据。题目内容在正文，不在头内重复存储stem/options/answer/explanation。文件内revision是文档声明，确认版递增编号由服务器分配，不能凭文件自报覆盖历史。

头JSON最多64KiB、嵌套32层，拒绝重复键和非有限数。根级未知元数据原样保留，不参与授权/评分；未知核心字段、块或版本拒绝确认，原文件及草稿保留，不静默删字段。自动检查/打开不重写文件。

## 可读正文

按固定顺序包含共享材料、题干、各选项、答案JSON、参考作答、解析。段由隐藏swq:section/endsection注释定界；块由单行JSON类型注释swq:block和endblock定界。普通Markdown读者会隐藏这些注释，显示正文、数学、相对图片、表格和选项。元数据/答案JSON围栏保留机器数据及来源，普通阅读也可查阅。

文本块仅在类型注释中存type，实际文本来自正文；HTML实体转义保护注释/标签，解析还原文本，保留字面HTML而不执行。公式块在类型记录中保留type/display，正文使用行内美元符或独立双美元符，解析后沿用受限TeX校验。文本和公式可直接修改正文。

图片/图表/附件/表格复用原协议完整类型记录，并生成普通Markdown可读投影。首版对这些结构块要求记录与投影一致：只改其中一份会明确报错，不能把可见修改忽略后继续评分。可同时修改结构记录与投影，或通过既有结构化资料工具生成新文件；本版不提供通用Markdown AST无损转换或所见即所得表格编辑。该限制不影响所有旧块/七种题型的准确往返。

答案围栏保存selected/blanks或rubric，缺答案必须显式为null，不制造占位标准答案。WrittenAnswer.reference来自单独的参考作答正文段。缺答案填空题必须声明独立blank_ids，选择题仍需要有效独立选项；主观题和所有缺答案题提交均待人工批改。七类题型和原有有答案判分规则保持。

## 相对附件与来源

attachments将文件内逻辑附件ID映射到assets目录下单个相对文件，携带SHA256/MIME；禁止网络/绝对路径、越界、编码路径和Windows大小写重名。单个附件16MiB、合计64MiB、最多200个描述。普通MD/打包目录能独立携带图片；确认前按同空间逻辑树解析、核对hash/实际类型，再把逻辑ID编译为本空间Resource ID，不信任文件中旧数据库ID。

来源中的人工验证/官方声明来自不可信文件时降为imported/unverified；AI模型/时间信息保留且不自动验证。来源原件ID只在本空间有效时关联，否则关联当前受管文件，原声明仍留MD快照。父题必须在同空间存在且关系无环。阅读材料正文与来源随确认版一起冻结，不改写旧全局共享材料。

## 确认、兼容与导出

普通保存只写工作副本，不更新标准答案。检查返回当前hash和上一确认版ID；确认必须携带两者与confirm=true，核对后写MD/附件快照、可追溯收据，再提交不可变question_versions并更新题目缓存。文件改变/版本竞争返回409；失败目录/收据保留，不自动回放或删除。外部程序仍可在最后检查后修改工作文件，下一次读取会显示未确认；已发布快照不被该修改覆盖。

文件已映射后ID不能原地改写为另一题。另一文件携同ID会拒绝，不按题干/名称合并。旧JSON题和旧提取MD分别提供预览→显式创建编辑副本→另行确认版本；旧ID、行、MD和Word/PDF原件不变。旧MD来源页码、区域、解析器版本、共享材料标识及未知非正文元数据保留为legacy_provenance。无答案资料的转换入口明确选择待批改主观题草稿，不推断真实题型或答案。

提交需要当前确认版ID；服务器校验不可变快照和版本归属后判分。request_id与答案/确认版一起幂等，确认新版本后仍可重试已保存的旧请求，不把它改成新作答。旧记录新version_id为null，保持版本未知，不能补造当时快照。

资料导出存在题目文件时使用manifest/questions缓存索引v2，全部旧缓存仍保留；question-files/<node>/question.md及assets是当前可读文件，versions/<version>/保存确认版MD/附件/编译索引。只有旧业务时维持v1。v2不是旧QuestionBundle v1，不能把混合缓存伪装成旧导入格式；可通过受管文件夹添加重新导入MD/附件，ID冲突仍需解决。此资料导出不含完整学习数据库恢复能力。

## 完整性与当前文件失效

确认前后核对MD，落盘后回读正文及全部附件；提交前再次校验快照MD、元数据和全部附件，损坏拒绝评分，不产生新attempt。读取图片及导出也逐个核对字节/hash。标题随确认内容冻结，预览当前变化不改旧标题/材料。

只移动MD而未同时维护assets相对目录可能使当前文件检查失败；已有映射返回invalid_current、警告及最后确认版，允许查看/作答快照，不能重新发布。当前文件缺失/非法同理；未映射文件没有该回退。导出当前附件无法校验时明确失败，不输出冒充完整的部分备份。复杂块投影编辑、未知版本/字段、导出v2兼容边界继续保留。实际验证见[R4记录](../dev/archive/reports/r4-validation-2026-10-26.md)。
