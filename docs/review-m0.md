# M0 自审

检查范围：入口/父子进程、API、数据迁移、演示题及作答、内容渲染、URL 策略、WebView 生命周期、锁文件、CI 和安装脚手架。

- 已修正非法 selected 元素可能触发集合成员检查异常；补充对象/null 输入测试，不写入作答。
- 主观作答只有 pending_review，score 为 null；源题与作答独立；后端读取答案，客户端不传分数。
- 媒体能力与业务令牌分开；只暴露启动时指定的一个文件；API 拒绝 Origin 与错误 Host；无静默下载、AI 或任意 shell。
- Windows 真实测试发现环境 dispose 通道问题；应用侧兼容见 ADR 0002，原始失败未丢弃。
- 同一 Flutter 构建目录不得并行运行不同配置，避免生成资源覆盖。安装包要在串行 release 后制作。
- 核心 Python 依赖已按官方当前稳定发行更新，锁文件与本地测试同步；单纯安装成功不是发行许可或干净机验收。

补充审查：题目入库前和判分读取时校验 QuestionDocument；选项 ID 从题目读取，新增非 a/b ID 的 API 回归。协议测试覆盖全部七种题型、富内容结构、AI 来源、共享文章、无效/循环引用和导出 Schema 漂移。严格解析不等于导入器可以删除未知原始资料。

剩余限制：运行界面仍仅固定演示题/text/latex；无完整题库/导入/媒体下载；JSON Schema 已导出，Dart 端校验/附件实际解析待 M2；URL DNS 预检有 TOCTOU，插件内部桥无法用当前版本设置禁用，外网页面安全矩阵未完成；M0 固定两个环境，动态页生命周期待 M1；字幕选择有代码但未人工测试，位置仅标签内保存；无 setup.exe；基于 Anaconda 的冻结物不作为正式发行。

本报告为当前实现自审，未使用独立审查 Agent，不声称独立人工审查已完成。
