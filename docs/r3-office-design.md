# R3后续：Word/PPT受控分页转换（2026-10-26）

当前实施与验证见[本批记录](r3-office-validation-2026-10-26.md)和[ADR0009](adr/0009-offline-office-previews.md)。LibreOffice将内部图表和OMML也归类为ActiveContent；仅通过输入门禁且包含这两类内部部件时启用其渲染，宏/脚本/OLE Automation关闭、外部关系与OLE对象拒绝，图表嵌入XLSX只允许静态值，选项版本v3。其余文档保持ActiveContent禁用。PDF成功须检查实际内容，不能仅凭退出码/页数。

用户允许继续下一步。延续R1–R6按序开发授权；人工及阶段统一待验，不创建子Agent，不操作个人库或发布/替换现有包。

## 需求与取舍

采用独立LibreOffice进程将受管DOCX/PPTX转换为派生PDF，再复用当前PDFium分页/缩放查看。DOCX保留现有结构预览。首批旧DOC/PPT不进入转换器，明确能力限制并保留原件；PDF不承诺保留动画、嵌入视频或任意复杂版式。转换由用户显式启动，不在普通打开时自动执行，不调用用户Office会话、不上传云端。

准备官方LibreOffice26.8.1 Windows x64离线运行时，原始MSI SHA256为c6298b10cfa1748bcbedad94c62ce771e240e5021bfd6d7a967cd571b04b5312。先在项目隔离目录下载/验证，再作管理镜像解包，不注册系统安装、文件关联或修改现有Office。运行时为可选离线包，主应用可缺省；缺组件时普通阅读/编辑/学习继续，UI明确说明转换不可用。许可、维护、实际体积及未验项在dependencies.md单列，冻结/发行只按已核清单打包。

## 顺序与任务拆分

1. 运行时实证：官方下载校验/签名、隔离解包、版本、许可/二进制清单；自编DOCX/PPTX中文/公式/表格/图表转换，PDFium页数/文字/页图及原件hash核对。
2. 输入与执行边界：只接受同空间节点ID和expected source hash；DOCX/PPTX32MiB、解压/条目/深度预算；拒绝加密、宏、外部关系、DDE/外部字段、危险嵌入或图片；原件不改。独立工作目录/profile，禁宏/不更新外部引用，固定可执行文件/参数，无shell；超时和取消只终止本次进程树，不影响用户会话。不把这些控制称为完整OS沙箱。
3. 0009追加document_previews任务/派生收据（来源ID/hash、运行时及选项指纹、状态、PDF路径/hash/页数、取消/失败）；不改0001–0008、原件与学习记录。复用轻量单worker编排，不建通用任务框架。有限排队，后台逐任务，重启标中断，不自动重读或重跑。
4. API：能力/最新预览状态、显式开始/取消/重试、状态查询及受保护派生PDF页图。成功需PDF实际可读、大小/页数、来源hash复核，原件/残留字节不清理。缓存按来源hash+运行时指纹+选项选用；文件变化/缓存损坏拒绝使用。
5. UI：DOCX结构/分页页内切换；PPTX生成幻灯片PDF预览；轮询、取消、明确失败与组件缺失；复用资源标签身份、PDF控件/位置及释放。标签关闭后后台任务继续，显式取消另行处理；后端退出会终止本次转换。
6. 自动化与审查：输入边界、缺组件/损坏/加密/超时/取消/重试/重启/缓存篡改/跨空间，0008升级/失败回滚/旧行与文件保持；双Python、Flutter、Windows真实交互、冻结无源码/受限PATH与离线运行时分别记录。未取得干净机实证不宣称干净机/完整发行验收通过。

## 保留边界

Word/PPT处理只生成派生预览，不提取正式题目、不改变标准答案。转换器来源清单/许可和缓存收据可追踪；不记录令牌、输入原文或用户路径到Git/日志。资料完整备份恢复、三方合并、独立无限期阅读位置与旧历史验收缺项不因此销项。R3剩余自动化/审查通过后再按task进入R4。
