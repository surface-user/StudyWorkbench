# 通用学习工作台开发路线

本文件维护已采纳的范围、任务依赖和交付目标。任务进度、下一项、测试结果及人工/阶段状态统一见[task](task.md)；当前能力边界见[架构](architecture.md)。不在路线中重抄逐批开发过程。

## 1. 产品目标

面向各类学习者，无Agent、模型或密钥也能完成资料阅读、媒体学习和自由笔记，再通过书签、位置备注、内部链接与检索找回学习痕迹。产品要求以[requirements](requirements.md)为准。

受管复制继续作为默认资料管理方式。每种格式分别确定留存、查看、学习标注、编辑和Agent可读等级，不承诺所有格式无损查看编辑或与Office等价。

## 2. 开发顺序

LW-00设计 → LW-01自由笔记 → LW-02位置书签/备注 → LW-03内部链接 → LW-04集中检索 → LW-05完整备份恢复 → LW-09首轮集成验证。

首轮流程之后推进LW-06格式扩展、LW-07视频下载，再实施LW-08。格式样本和下载来源/依赖调研可提前，但不阻塞首轮流程。LW-05备份与迁移设计从LW-00开始，每项新增数据从首个迁移即备份、校验并保留旧数据。

LW-08与R6剩余能力是同一任务，不另建Agent平台或重复统计完成。R6已实现切片及既有PR继续交付跟进，不能用新增排期取消原审查/当前head CI义务。

## 3. 范围边界

- 首轮不要求拆题、作答或调用模型。普通学习流程与题目、标准答案、历史版本保护并存。
- LW-06优先补通用UTF-8文本/JSON查看及XLSX多表只读，明确公式缓存和Office静态预览边界；旧DOC/PPT/XLS、编辑能力和新组件先评估。
- LW-07先确定有权获取的来源、目标目录、质量/恢复策略及固定组件许可，再实现入库、队列、取消/重试/恢复、去重与磁盘预算。登录、DRM和通用转码不默认为首批支持。
- LW-08先围绕既有题目分析完善显式授权与独立人工审核；按2026-11-05用户要求，首批不接模型、不下载模型或配置凭据。模型接入后排，资料解释、提纲和资料比较等候选场景分别确认，不把候选全部视为已授权需求。
- 外部目录原地工作区/监听、完整代码IDE、Office等价编辑不自动加入本轮范围；主要技术栈或数据权限变更按项目规则另作决策。

## 5. 已确定的任务顺序与实施范围

下表为交付目标，不表示各项已实现或通过。保留既有人工统一待验安排；功能实现、自动化、自审、实际窗口、用户人工和阶段验收分别记录。首轮流程交付必须包含LW-05恢复与LW-09集成验证，现有export v1/v2不能替代。

| 编号 | 范围和依赖 | 必须形成的结果及验证 |
|---|---|---|
| LW-00 | 需求、交互与契约设计；无前置功能依赖 | 用一门课程的PDF/课件/MD/视频走查；确定笔记权威、位置/版本和内部链接协议、删除语义、格式等级、备份范围；更新相关模型/API/安全设计，涉及架构决策追加ADR；未设计的协议不得先实现 |
| LW-01 | 自由笔记；依赖LW-00 | 工作空间内直接新建、编辑、保存、重新打开笔记；可由资料进入且不依赖拆题/作答/模型；兼容现有数据库笔记和MD副本，覆盖草稿、冲突、失败和重启 |
| LW-02 | 通用位置书签与备注；依赖LW-00/01 | 首批PDF页、视频时间点、MD/TXT可验证位置；支持多条命名书签、备注、回跳与重启保持；改名移动保持身份，源变化/锚点失效明确提示；文本选区/图像区域等更精细定位按协议逐步扩展 |
| LW-03 | 笔记/资料/书签位置的内部超链接；依赖LW-02 | 创建与跟随链接、往返导航、跨空间校验和移除/失效提示；外部HTTPS继续隔离，不引入任意file路径或网页业务桥 |
| LW-04 | 学习记录集中查看与搜索；依赖LW-01/02/03 | 检索笔记文字、书签标题和备注，结果跳回来源；保留已有资源名搜索，明确不把该任务等同于任意格式全文/OCR；分页和隔离回归 |
| LW-05 | 完整学习库备份恢复；设计依赖LW-00，集成覆盖LW-01至04 | 覆盖原件/工作文件/笔记/书签/备注/链接/确认版/作答/事件/媒体状态及关系；实际恢复、hash/数量/关系一致性、失败回滚与旧数据保留；不能把当前export v1/v2当替代品 |
| LW-06 | 学习格式扩展；依赖LW-00，优先排在首轮学习流程后 | 维护留存/查看/标注/编辑/Agent可读矩阵；通用UTF-8 TXT/JSON、XLSX多表只读与公式缓存边界、Office静态预览逐项验；未知/坏文件及编码明确反馈；新依赖先完成项目规定审查 |
| LW-07 | 视频获取与本地下载；依赖LW-00与既有媒体服务，批量使用前接入LW-05 | 首批来源、目标目录、质量策略和组件审查明确后实现队列、取消、重试/恢复、去重、磁盘预算与入库；覆盖真实授权来源流程、失败与重启，保留现有媒体记录 |
| LW-08 | R6剩余模型/凭据/资料读取及审核；依赖LW-00/01至05及对应格式提取能力 | 首批复用授权切片，完善所选学习记录/历史确认版受控读取、引用、候选修订与普通UI独立采用；不接模型/凭据。后续指定资料、模型/安全凭据与远端授权须另经确认，再逐项评估其他助手能力 |
| LW-09 | 无Agent学习流程集成验证；依赖LW-01至05 | 用隔离样本实际完成导入、阅读/播放、记笔记、标记位置、跳转、查找、重启与恢复；自动化、Windows实际窗口和用户人工/阶段分别记录；LW-06/07/08扩展后补对应回归 |

各项开始前明确本任务报告、提交/PR、审查与当前head CI要求，退出执行[任务条件](task.md#任务退出条件)。未授权自动推送、合并或发行，历史失败和个人数据继续保留。

## 6. 设计未定项与讨论来源

笔记权威、锚点、内部链接、恢复协调/精确排除及当前格式预算见契约；后续格式/编辑扩展、LW-07来源/下载组件、LW-08模型/凭据及其他场景须在对应任务实施前细化。

初始差异评估作为[方向任务的讨论输入](../dev/records/2026-11-03-learning-workbench-direction/gap-review.md)保留，不是第二份当前路线；采纳过程见[同任务报告](../dev/records/2026-11-03-learning-workbench-direction/report.md)。
