# 旧提取Markdown v1兼容规范

当前仍兼容该格式；它没有文件内稳定题目ID，不等于[QuestionFile v1](question-file-spec.md)。旧MD不在打开时静默升级，不改源Word/PDF，转为可判分题需显式编辑副本及另行确认。

该格式单元为 MarkdownQuestion，与需要题型/标准答案的 QuestionDocument 分开索引。原件资源共享，每个题目有独立ID、标题、Markdown资源、来源资源、来源页/区域或Word内容顺序。转为可判分练习题需要单独的人为确认，不自动推断题型或标准答案。

磁盘组织为数据目录下`workspaces/<workspace>/questions/<id>/question.md`及同目录`assets/<resource-id>.png`。MD使用UTF-8，图片相对引用`assets/...png`，公式使用数学标记，Word表格保留Markdown。末尾JSON元数据记录原文件名/SHA256/资源ID、来源页、裁切区域、解析器版本、unverified及not_inferred。索引由SQLite管理；文件内容和哈希仍受资源API校验，不将本机路径/令牌交给网页。

PDF：仅对可提取文字的显式题号做保守候选识别，保存单栏全宽原貌裁图及提取文字，跨页延续到下一题号；裁图保存公式/插图，提取文字不代表公式识别。区域坐标为从左上角起的归一化`[left,top,right,bottom]`。Word：按内容顺序切分显式题号/可恢复自动编号，保留公式、图片和表格；不声称有实际分页裁图。

先预览候选、核对并选择，再明确确认；预览不写正式MD题目索引。确认带候选内容摘要、选中下标及confirm=true，写入事务串行，重复同组选题返回既有记录；另一组选题不覆盖已入库批次。正式确认后旧解析任务不可覆盖。原件和整篇资料预览仍保留；整篇另存笔记与逐题MD是两个明确入口。

无题号/扫描无文字时不编造候选。题号支持行首阿拉伯数字加点/顿号、第N题（阿拉伯数字或一至九十九的规范中文数字）及【N】；括号小题、章节“一、”和小数不独立拆题。重复题号按出现顺序保留不同候选并警告，不按题号覆盖或合并。数字列表与题目含义不能仅靠语法确定，仍须核对候选边界。

共享材料仅支持独立一行的显式标题“阅读下列材料，回答第N至M题：”或“Read the following passage and answer questions N-M:”，N/M为阿拉伯数字，连接符支持至/-/—/–、冒号支持中英文。标题至首题之间的内容作为材料，后续题号必须与闭区间N至M完整一致、顺序相同且不重复（最多200题），到下一材料标题、区间外题号或文档末尾时才关联；缺号、重号、乱序、反向或超限范围拒绝自动关联并警告。其他卷头/材料仍保留在原件与整篇预览，须手动归组。自动关联只形成未确认候选，不推断题型/答案或发布确认版。

材料可跨Word内容块或PDF页，PDF材料有独立的原图裁切、source_pages及regions；题目自己的来源区域保持独立。材料ID在同次解析中按出现顺序分配，随每题MD保存非正文材料来源元数据，图片相对引用随题目复制/导出。Word不虚构页码。解析器版本builtin-4-grouped-md只用于新的解析任务，不重写旧MD或确认历史。默认整篇解析沿用单栏。显式双栏页段及扫描页文字预览见下方专节，任意嵌套编号与隐含材料语义仍待支持。

确认前可改标题、合并相邻候选、分割Word内容、水平重裁PDF并手动归组共享材料，改动以expected_revision校验；已存MD不由旧预览回写。PDF手工子裁图仅保留精确图像，不复制无法定位的原提取文字。当前检索仅标题，分批加载；原文全文检索和该旧格式自身不直接判分，显式转换见下方R4兼容入口。

原件8MiB、PDF20页、解析25秒、200个候选、图片总量64MiB预算延续。源文本可能含HTML/链接，界面以纯文本或受控块展示，不执行其脚本。每个MD附的图片副本在题目目录，导出另附`questions/<id>/question.md`和相对assets目录，离开原数据目录仍可打开；它不等于整库恢复包。

正常写入检查所有选题的源资源后落盘。进程崩溃/磁盘失败可能留下未登记的派生MD/图片目录；它们不是原件，不自动删除。离线完整性巡检已按资源索引识别`workspaces/<workspace>/questions/<id>`的未登记目录（含空目录及仅写入图片的中断），只提示`unreferenced_derived_candidate`；不会补登记、重写或删除文件。已登记题目的MD沿用资源大小/hash校验；巡检另读取旧题目blocks及shared_materials中的image引用，核对同空间MD资源与固定题目路径，再按同空间原附件Resource的大小/hash核验assets副本。原附件或MD绑定无效分别报告invalid_legacy_attachment_reference/invalid_legacy_question_reference，损坏JSON返回不完整；仍不证明全部业务元数据语义。图片副本缺失/变化只报告，不从原图自动补回；候选的后续恢复语义见[派生题目恢复契约](#derived-question-recovery)。持久化成功以API响应/索引/哈希为准，不能只看有目录就断言入库。

## 派生题目的恢复与重新登记（规划）

旧版落盘顺序是先写图片副本和 `question.md`，再提交题目、MD 资源和导入批次的登记。巡检发现的目录可能完整、只含图片或为空。现行版本支持只读巡检；以下是后续后端恢复入口的约定。

**选定来源。** 用户在当前空间指定一个未登记的题目目录 ID、一份仍保存候选的导入批次及题目序号。客户端只传业务 ID、序号和预期候选修订。服务端从固定目录和已登记资源定位内容。进入核对前，验证空间、目录名、登记归属及路径；不跟随链接、重解析点或候选 MD 中的路径。目录名、题号和文件尾部 JSON 均不能证明历史归属。

**只读核对。** 从同空间已登记原件重算 SHA256，核对批次、解析器版本及候选修订。用写题流程相同的序列化规则从选定候选生成预期 MD 字节，包含共享材料、图片引用及分块任务的选区。逐一验证预期附件的资源 ID、长度、SHA256、所属空间与候选目录中的副本。目录必须恰含该题预期成员；未知成员、缺少 MD、缺图、原件失效、来源不足、无权限或核验超限都保留原状并给出原因。按资源各自的原件限额处理，图片累计最多 64 MiB，MD 最多 8 MiB，至多处理一个候选目录，不遍历全库猜测来源。

核对结果显示所选批次、序号、来源版本、附件数、候选状态及可确认内容的摘要。摘要绑定空间、目录 ID、原件 ID 和摘要、批次、修订、序号、MD 摘要及按资源 ID 排序的附件 ID/长度/摘要。相同字节只能证明与用户选定的候选相符。若同批有多个无法区分的序号、已有登记冲突或输入已变，返回冲突并保留证据。预览本身不写文件、索引或确认收据。

**确认、重试与恢复。** 用户显式提交请求 ID 和刚核对的摘要。服务端重新读取原件、候选与附件，并重新核对目标登记。只在新 ID 的题目位置生成文件，使用独占创建，保留未登记目录、已确认题目和原件。题目、MD 资源、与所选批次/序号的对应关系及成功收据在同一事务内提交。遵守原批次的选题规则，不能用恢复入口追加或更改已确认的选题；单题恢复必须先明确告知其将确认的选题集合。相同请求和摘要重复提交返回同一目标；请求 ID 绑定不同内容、已由另一请求确认或事前绑定不再成立则返回冲突。重新启动后按收据识别已提交结果；此前只写了部分文件的操作保留文件并重新核对，不把磁盘残留登记为成功。

**其他派生目录。** `working` 的工作副本和保存恢复点沿用已有另存流程；`question-files` 与 `question-versions` 还需各自的来源映射、修订及确认关系，只读巡检继续保留。Office `previews` 依赖转换任务、原件摘要、转换参数及派生 PDF 摘要；缺少任务记录时只显示未登记状态。以上目录均不能作为旧提取题目导入。完整备份仍可保留未知字节。

自动化验收覆盖完整候选、仅有图片、未知附件、共享材料、已有确认和变更后的原件；验证跨空间拒绝、超限中止，以及并发重复确认和提交前后重启。失败保留候选和原件字节，成功后以同一收据核对目标行、附件和新目录，再验证完整备份与恢复。

## R4兼容入口

本文件描述的旧提取Markdown v1保留原行和原字节。新[QuestionFile v1](question-file-spec.md)单独编号；旧题详情的“创建可编辑题目文件”先显示预览，显式创建稳定ID映射，再另行发布确认版。旧MD不猜测答案，转换为明确待批改的主观草稿；页码/区域/解析器/来源原件hash及未知非正文元数据随legacy_provenance保留。已有同ID旧JSON冲突拒绝，不自动合并。详见[R4记录](../dev/archive/reports/r4-validation-2026-10-26.md)。

## PDF 分块提取

内部解析子进程已支持指定一段 PDF 页码，返回原始页码、页图、区域、标记行及接续片段。缺少可靠坐标的页面带布局不确定标记，整页保留供核对。后端已有持久化任务、分页状态、逐块推进、取消及恢复接口。全部所选页就绪后可生成候选，复核并显式确认所选题目。选区内按实际页号裁切，导出题目保留原始页码和所选区间。桌面分块交互另行规划。

用户从当前空间的一份托管 PDF 选择连续页码，页码从 1 算起，起止页均包含。任务绑定空间、资源 ID、原件 SHA-256、解析器版本及所选区间。同一绑定的重复创建返回已有任务；变更区间或版本需另建任务。已有整篇导入继续使用原有入口。分块结果仅供预览，题目仍须经现有确认流程入库。

**输入与预算。** 页段任务支持已托管的不超过 128 MiB、最多 2000 页的原生 PDF，每个任务最多选择 100 页。顺序执行，每块至多 20 页、子进程至多运行 25 秒，同时执行的文档子进程沿用阅读侧的并发上限 2。按原件绝对页码输出页图、题目区域和文字。父进程在接收时限制单块输出最多 96 MiB，并对解码后的图片累计计费。整项任务最多 200 个候选，图片合计最多 64 MiB。阶段内超限即停，重试沿用已提交的计数。超过 8 MiB 的 PDF 通过资料添加入口复制到工作区；创建任务和执行区块时，从托管原件分块计算 SHA-256，同时生成只在本次调用存活的可定位文件快照。工作进程按需读取该快照。恢复、提交结果和首次确认均再次流式核验原件。整篇上传、双栏单页阅读及扫描页 OCR 沿用各自的输入限额。

**区间边界。** 块尾未闭合的题目或共享材料保留为待续片段，以原件页码和区域排序。下一块只能承接紧邻的上一块。所选起点之前的题干或材料未知，末页也可能截断题目；这两处分片以警告展示，不能拼到区间外的内容。显式重复题号保留各自位置。仅当整个区间完成并核对累计预算后生成可确认的候选修订。

**进度、取消与恢复。** 服务端先核对空间、原件路径、长度、摘要和页数，再领取下一块；在开始或恢复时重新核对绑定。每块在数据库事务外解析，以任务 ID、起止页和当前执行代次为提交条件，一次事务登记派生产物引用、已完成页数和下一页。同一块重放只计一次。轮询显示已提交页数、所选总页数和状态；运行中取消使当前代次失效，迟到结果不能提交。已提交块保留，取消或失败后由用户显式恢复。进程重启将遗留运行任务转为已中断，可从第一个未提交页恢复。原件变化或解析器版本不符时拒绝恢复；已确认题目不随解析重试而改写。暂存文件不参与索引，也不触发自动删除。

**自动化验证范围。** 自编跨 20 页的文档要验证原页码、跨块续题、材料跨块、无题号页和截断提示；非法区间及超预算应在相应边界拒绝。对同一块注入取消、超时、重复领取和提交前后进程中断，核对已完成页数、候选摘要和附件引用。以原件字节及旧整篇解析回归核实兼容性，再在冻结包运行同一条用户路径。

## 双栏阅读和单页离线 OCR

**已实现的原生文字双栏预览。** 后端支持按节点选择托管 PDF 的一页，显式读取等宽、水平、从左至右的双栏。每个文字对象须能落入单侧，每栏各行在纵向需能分开。后端核对空间、原件摘要、页号和 PDF 预算。左右两栏各自从上向下读取，返回各栏文字及相对原页的左上角归一化区域，另附原件摘要与原页号。原页始终可查看。空栏、跨栏字形、旋转或无法判定位置的文字给出具体提示并退出自动排序。标题跨栏、表格、竖排、从右到左的栏序和扫描页另行处理。整篇默认单栏与既有分块任务沿用各自的解析版本。

**双栏页段拆题。** 显式选择 two_columns 的页段任务采用 pdf-column-chunks-v1。每页依次读完左栏和右栏，可将右栏开头的续题连接到左栏末题。题干及共享材料各自保存原页号、栏内裁图和归一化区域。同页跨栏的题目保留两段裁图，来源页号只记一次。图形跨中线、切分边界穿过图形、旋转和重叠等不确定页面只保留整页图，并中断题干与共享材料接续。仅对完整、有序的显式材料范围建立关联。候选复核、逐题选择及确认沿用原有修订流程。旧单栏任务仍按原版本恢复。

**已实现的扫描页后端预览。** 用户指定活动工作空间中的 PDF 节点、原件摘要、页号和简体中文或英文。后端用核验过的本地组件识别该页，返回未确认的文字和各词相对原页左上角的归一化包围框，附模型摘要与版本。每个词保留引擎的 0–100 置信分，有词低于 60 时提示 low_confidence。空白结果提示 no_text，超出 20000 字符或 4000 词区时返回已收集内容及 truncated 提示。请求只接受固定语言选项。任务结束前再次核对空间、节点、原件绑定和实际字节。预览仅随当前请求返回，取消、超时和重启丢弃本次结果。题目及标准答案继续通过原确认流程写入。

**首版预算与验证。** 沿用 8 MiB 原件、2000 页上限、两个文档处理槽。单个所选页图最长边 2048 像素，单次最多 25 秒，返回文字最多 20000 个字符。自编两栏交错对象顺序、跨栏标题、空栏、旋转页及无文字页分别验证栏序、原坐标或拒绝。OCR 使用自编的中英文印刷字和空白页，对照已知文字与框的位置，覆盖缺失或被替换的语言包、取消、重启和冻结包。后台不自动下载引擎或语言包。
