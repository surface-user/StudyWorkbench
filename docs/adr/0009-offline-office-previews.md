# ADR 0009：可选离线Office分页预览

状态：按用户继续开发授权实施；人工、干净机及阶段验收待统一进行。沿用Flutter/Python技术栈，不调用用户Office会话。

DOCX/PPTX由固定LibreOffice26.8.1 Windows x64独立进程生成派生PDF，复用PDFium逐页阅读。官方MSI逐包hash/Windows签名验证，管理镜像解包；锁定逐文件清单、入口和许可，执行前完整校验。运行时为可选离线组件，默认主包不包含；缺失时Word结构预览和其他业务仍可用。准备/打包脚本不替换已有目录或注册系统安装。

输入最多32MiB，解压合计128MiB、4096条目、一次受限XLSX嵌入；XML单部件8MiB、合计20万节点、深度128，增量解析到预算即停止。拒绝宏、XLM宏表、OLE/ActiveX、外部关系（含编码路径）、DTD/实体、DDE/拆分外部字段、外部公式、非PNG/JPEG媒体。图表XLSX仅接受静态单元格，任何工作簿公式/定义名称均拒绝。旧DOC/PPT、动态或不支持部件明确拒绝，原件保留。

每任务独立profile/工作目录/环境；关闭宏、Python脚本和Windows OLE Automation，Writer不更新链接。无内部图表/OMML公式时同时禁用ActiveContent。实测发现该总开关也会隐藏正常内部图表和公式，因此仅对通过上述输入检查且含内部chart或OMML部件的包启用内部渲染；不放宽OLE/外部内容入口。选项版本升为v3，旧v1/v2缓存不作为当前选项缓存命中。修复前占位图与修复后公式/图表页图均保留证据。

固定参数、无shell，Windows原生进程挂起创建后先加入Job再恢复，防止子进程逃过所属Job。Job限制总内存1GiB/4进程、句柄关闭结束本次进程树；转换执行限90秒，完整运行时验证时间另计且可取消。单worker、最多4个待办，后端退出时结束所属转换；不终止用户Office或其他同名进程。这些控制不是完整OS文件/网络沙箱，不宣称任意不可信Office文件安全认证。

0009仅追加document_previews收据：空间/节点/源Resource及hash、运行时与选项指纹、状态、PDF路径/hash/大小/页数、取消与错误。源文件不可变；重启将未完成任务标中断，不自动重跑。缓存读取同时核对源和PDF；篡改/丢失拒绝，显式重新生成留新任务，不清理失败字节。0001–0008不修改，旧行和工作副本保持；回滚依赖保留备份，不进行破坏性降级。

完整发行许可/SBOM、安装升级卸载、普通用户/干净机、复杂版式/字体和更广第三方样本仍待验。静态PDF不承诺动画/视频，拒绝项可在外部转PDF再添加。实际命令与证据见[本批记录](../r3-office-validation-2026-10-26.md)。
