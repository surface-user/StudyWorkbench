# ADR 0003：用户授权提前开发 M1

日期：2026-10-24。状态：采用；来源为用户明确要求“那 M0 的问题暂时先忽略，开发 M1 吧”。

允许提前实现 M1，不把 M0 改为已通过。Release 启动故障、浏览器工具中止、IME/DPI/性能和用户验收继续沿用各自证据边界。技术栈、依赖、数据保护与受控 API 规则不变。

第一批交付 M1-01 与 M1-02 的工作台垂直切片：侧栏工作空间创建/重命名/确认移除/恢复；每空间独立题目与追加作答；动态题目/网页/播放器标签、新增/关闭/重开、快捷键与服务端布局持久化。移除采用可恢复归档，不删除题目、作答或 profile；至少保留一个活动工作空间。未来永久删除另需单独确认与数据生命周期设计。

Alembic 0002 将 M0 题目/作答归属 default 工作空间，题目主键改为 workspace_id+id，作答使用对应复合外键。已有数据库升级前以 SQLite backup API 保存一致性副本，事务包裹 DDL；失败回滚且保留备份。保留 M0 API 为 default 空间的兼容入口，绝不根据当前 UI 空间暗中改变旧入口作用域。

布局保存在各 workspace 的版本化 JSON 中，限制标签/关闭历史数量，校验 active id、唯一 id、类型、URL 和草稿长度。不保存 WebView token 或媒体能力 URL。各网页/播放器使用 workspace_id/tab_id 区分 profile，只按需创建原生视图；切页保留已打开视图，关闭真正销毁。历史网页当前 URL 与主观草稿通过受保护业务 API 保存，外部网页无业务桥。

M1-03 数据根选择/迁移和 M1-04 进程/安装包继续单独实施与验收，本批不声明整个 M1 完成。
