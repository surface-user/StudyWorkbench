# ADR 0005：持续开发与统一验收、M2 首批导入

现行关系（2026-10-30整理）：M2首批预算/范围是历史决策，后续查看器与layout预算由[ADR0008](0008-resource-tabs-and-document-workfiles.md)补充；导入8MiB预算仍保持。开发主线已转R1–R6，人工延后不豁免最终任务退出条件。

日期：2026-10-24。状态：采用。

用户要求“阅读 agent.md，继续开发，暂时不验收，task.md 任务完成之后统一验收”。据此允许按 M2–M5 顺序继续开发，不以各阶段人工验收阻挡后续实现；自动测试、审查和证据记录仍执行。M0/M1 未验证项与失败证据保留，人工和阶段验收均不标为通过。不包含发布、合并或删除学习数据的授权。

M2 首批复用现有 Python 标准库和题目协议，提供有工作空间作用域的二进制上传、原件保留、SHA256 去重、解析版本/失败记录、预览和显式确认接口。JSON 题目 bundle 先校验来源与完整引用，再原子写入题目和共享阅读材料；文件自报 official/human_verified 降为 imported/unverified，AI 保留 ai_generated 和生成信息但降为 unverified。已存在题目 ID 冲突时拒绝，不覆盖答案或作答。文本、Markdown、HTML 先提取为笔记预览，不猜测标准答案。HTML 仅提取文本，不运行脚本或请求链接。

原件由服务器生成资源 ID 和相对路径；文件名仅作显示元数据，接口不接受服务器文件路径。导入请求上限 8 MiB，普通请求维持 64 KiB、布局 2 MiB；实际流式计数，不能通过省略 Content-Length 绕过。资源只经鉴权 API 按 ID 读取，拒绝重解析点、越界路径和篡改后的文件。不向网页传递业务令牌或文件地址。

图片和附件引用必须同属工作空间，图片限定 PNG/JPEG 与尺寸上限；富内容表格使用原生 Flutter 组件渲染，图片通过私有 API 读取字节。上传的资料未确认前不写正式题库或笔记；解析失败保留原件和错误。确认可重复调用且不会重复写入。相同原件在同一空间返回原有任务；不同空间独立保存。

Word/PDF 解析、Docling/MarkItDown 真实样本比较、大文件/视频导入及完整 Dart 协议校验另列 M2 遗留项；本批不引入尚未审查的新解析依赖。技术栈不变。
