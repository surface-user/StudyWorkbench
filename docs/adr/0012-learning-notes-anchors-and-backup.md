# ADR 0012：自由笔记复用MD、版本化位置与整库恢复

2026-11-03。状态：**设计已采纳；分项实现、验证与人工状态见[task](../task.md)。** 用户已要求按学习工作台路线推进，本文记录LW-00决策与LW-01细化，不改主要技术栈，不新增依赖或Agent权限。

## 依据与选择

现有MD工作副本已有保存收据/冲突/草稿，旧notes已有富内容编辑与R5关系。新自由笔记复用MD资源节点和DocumentWorkfile，以当前文件为编辑权威；旧notes保持数据库权威、原ID及既有编辑协议。不把两者后台互转/双写，不新增第三套正文。Markdown可导出携带，完整学习关系仍依赖完整备份。新建意图允许一次创建原件与可编辑副本，用专用持久幂等收据保护创建失败/重试。

书签/备注以稳定节点ID及LearningAnchor v1绑定内容hash；PDF页、派生PDF页、媒体时间、MD/TXT原文行各有判别字段。内容变化必须显式提示，重新关联保留旧锚点修订；树内改名移动不改身份。内部链接只用严格版本URI和业务解析，不开放系统路径、网页桥或跨空间隐式访问。

完整备份首批采用离线整学习库快照，恢复到新空目录，校验文件hash、数据库行及关系再提交配置；保留旧数据、墓碑、失败字节和草稿，排除会话授权/令牌/能力/凭据。当前资源export v1/v2及relocate都不等于该能力已实现。

## 与既有决策的关系

本决策扩展[ADR0008](0008-resource-tabs-and-document-workfiles.md)的MD工作副本用途，不替代其保存/恢复规则；沿用[ADR0007](0007-resource-explorer.md)受管树和稳定身份，不引入外部原地工作区。沿用[ADR0011](0011-learning-record-projections.md)旧笔记/作答事件语义，文件笔记关系另用判别目标，不重写旧事件或评分。沿用[ADR0004](0004-data-root-and-lifecycle.md)数据锁/迁移保护；产品备份扩大到新增学习记录，不能把迁移工具改称已验收恢复功能。此前原件、确认版及历史保护规则均继续有效，无被替代条目。

## 取舍与验证

LW-01实施补充（2026-11-03）：已追加0013和自由MD创建/恢复UI/API，人工待验；其余决策仍规划。创建ID与节点ID共用、原件ID独立，规范请求JSON负责幂等，初始MD/hash/路径确定性派生，避免冗余列；新增分页创建收据查询，解决客户端重启后丢失请求ID无法恢复的问题。初始MD固定带创建ID注释。此细化不替代旧保存收据/冲突规则，也不迁移旧notes关系。

保留两种现有笔记格式需要读取适配，但避免有损迁移和新正文镜像；MD初始原件与其他格式同hash时须测试查看器按原件后缀分流的冲突。hash不匹配先提示失效，不承诺自动重定位。整库恢复实现较明确，单空间合并留待单独设计；全库备份的隐私范围必须在UI说明。

字段、预算、分批表/API、设计课程走查和故障门槛详见[契约](../learning-workbench-contracts.md)。LW-00只形成设计，LW-01随后从实际head追加0013，并补同空间MD/MARKDOWN枚举供已有笔记选择；原件格式判断不依赖可改的节点显示名。未操作个人库，人工统一待验安排保持，未新增提交/推送/合并/发行授权。
