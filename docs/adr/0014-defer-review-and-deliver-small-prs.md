# ADR 0014：暂缓审查与按小任务提交PR

2026-11-10，状态：按用户明确指令采用；仅调整本批工作安排，不改变产品架构或数据权限。

## 背景与范围

用户要求阅读AGENTS/task并分析完整SBOM、传递许可、漏洞、签名与发行准备，Office整包Java桥接依赖，复杂文档解析、下载和既有规划功能；同时要求“暂时忽略审查和人工测试，直到所有任务完成”“每完成一个小任务记得提交pr”。既有已实现切片不得重复开发，未定功能不得因“所有任务”被扩展为无限范围。具体切片、依赖和状态由[task](../task.md)维护，分析与实际命令续记[发行原报告](../../dev/records/2026-11-10-release-integrity/report.md)。

## 决定

1. 本批开发/PR代码审查暂缓至本批任务完成后集中处理；不执行独立审查、请求审查或为此创建子Agent。状态为“按用户要求暂缓”，既有审查及失败记录保留，不补记通过。集中审查是后续任务，不阻塞本批已测开发切片提交PR。
2. 人工测试/Computer Use继续暂停；不等待此前Release清单/用户反馈，不重启窗口或安装验收。此前清单/用户反馈和失败保留，恢复测试须后续明确安排。
3. 相关自动化、当前head CI、资料/权限/协议保护及用户本次明确列出的传递许可和漏洞检查继续。暂缓代码审查不影响产品中的候选审核、采用/删除确认和远端授权；不接模型/凭据的原约束继续。
4. 一个可独立说明与验证的小任务对应一个提交范围和草稿PR；依赖未合并PR时明确base/head。失败保留，CI未查询/失败保持待交付；不以父PR或旧head结果替代。不同切片可继续准备，不因待审停止开发。
5. 开发切片以实现完成、相关自动化通过、原报告更新、独立PR及当前head CI通过为开发交付条件，另列审查暂缓、人工暂停和发行状态。待所有本批切片完成再处理集中审查；实际签名/正式发行、合并、删除数据不由此获得授权。

## 替代关系与限制

本决策在本批范围内替代[ADR0013](0013-cancel-manual-testing-and-bound-artifacts.md)中“代码审查继续”的执行时点，延续其不执行人工测试和限制产物留存的规则；也覆盖task/其他现行文档中冲突的审查前置安排。2026-11-10较早的用户自行测试交付作为历史保留，此后不等待该反馈。ADR0013其余数据、自动化和留存要求不变。

暂缓不表示已审查、已验收或可正式发行。签名身份/服务未指定、下载目标站点/OCR组件等未定项须明确记录；这些局部输入缺失不妨碍其他已确定任务推进。
