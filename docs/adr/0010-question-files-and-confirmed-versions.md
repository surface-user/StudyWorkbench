# ADR 0010：题目文件与不可变确认版

状态：按R1–R6继续开发授权实施；人工、普通用户/干净机及阶段验收待统一进行。

QuestionFile v1以UTF-8 Markdown保存稳定题目ID、正文、元数据和相对附件，独立于旧QuestionDocument v1与提取Markdown v1。复用已有七类题型、富内容块、受控来源和判分规则；仅新文件协议允许显式空答案，所有空答案提交待批改。根级未知元数据保留，未知核心结构拒绝确认；结构块投影不一致时拒绝，避免忽略可见编辑。格式与预算见[协议](../question-file-spec.md)。

旧JSON/提取MD只经预览和显式创建建立新文件映射，保留原件与旧行。工作副本保存不发布答案；另行确认时核对文件hash与上次确认版，冻结MD、标题、编译内容、共享材料和附件并回读校验。失败字节/收据保留，不自动重放。当前文件无效或相对附件丢失时允许读取已确认快照，禁止隐式修复和发布。

0010仅追加question_files、不可变question_versions及attempts.question_version_id。版本更新/删除、跨空间绑定和修改历史绑定由数据库触发器拒绝。旧0001–0009不改，旧作答不补造版本；仍为null/版本未知。新题提交校验当前确认版及全部快照资产；已保存请求可按原request_id、答案和版本幂等重试，确认新版本不改旧分数。

文件编辑草稿与作答草稿分别保存；标签关闭只保存/丢弃草稿，不提交答案。复用既有PageHost隔离隐藏视图焦点。带文件映射的导出明确为v2，附可独立阅读的当前MD/相对附件和所有确认快照，不冒充旧v1导入包或完整恢复备份。

无新产品依赖，不改技术栈或固定玻璃库。复杂结构可读投影的编辑限制、单独移动MD导致相对附件失效、历史版本未知及未验收边界明确保留。R5的追加学习事件、完整反向关联和R6仍按顺序实施。自动化与失败记录见[R4交付](../../dev/archive/reports/r4-validation-2026-10-26.md)。
