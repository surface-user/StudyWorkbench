# ADR 0007：R1受管资源目录与统一添加

状态：用户明确确认最小调整方案并授权本轮R1；设计/实现已执行，人工与阶段待验。

沿用Flutter + Python及既有Resource/ImportJob/MediaEntry，不改技术栈、不新增依赖。0007只追加逻辑目录/复制任务及复合引用需要的唯一索引；不搬旧文件、不改题目/作答/草稿/媒体播放数据。稳定逻辑身份与blob hash分开。首批复制导入保留来源目录，Windows路径/重解析点、名称、预算和取消由Python控制。

新库/新空间默认从空工作区添加资源；已有空间名和v1布局原样保留，旧业务视图作为辅助工具。资源标签、文件查看器/编辑器、题目MD、记录贯通和Agent仍属R2–R6，不提前实施。

迁移只在生成的隔离旧库及副本上验证；备份、失败回滚和原记录比较见[R1验证](../r1-validation.md)。不读取个人学习库，不更新旧开发包，不替代M0/安装/人工或阶段验收。
