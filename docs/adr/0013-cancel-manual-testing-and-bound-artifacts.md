# ADR 0013：取消人工测试与限制开发产物留存

2026-11-06，状态：按用户明确指令采用。

用户明确“取消人工测试”，要求继续开发并处理项目接近30GB的问题。此决策替代[ADR0005](0005-deferred-acceptance-and-imports.md)中延后人工测试、最终统一人工测试的安排；不再执行或等待人工测试、Computer Use、实际窗口/人工安装验收，也不以此阻塞开发或任务退出。取消的测试记“用户已取消”，不改写历史失败或补造通过。

需求、设计、实现、相关自动化、代码审查、报告及PR当前head CI继续执行。普通产品中的用户授权、候选人工审核、删除确认和资料保护不受影响；模型继续暂不接入，合并和发布仍需用户授权。

开发产物只保留一份当前冻结后端、一份可用可选Office组件及必要开发依赖。通过测试的tmp_path用pytest内置failed策略自动清理；失败时保留现场，提炼最小复现、JUnit、错误日志、转储及源码版本后可按明确清单移除重复构建/组件/测试副本。不得按目录名称猜测个人库，清理前确认路径、用途和重解析点边界，不删除源码、个人资料或未提交工作。日志和清单仍在artifacts，过程继续原任务报告，不另造清理报告体系。

2026-11-10补充：本批用户要求暂缓代码审查至任务完成后集中处理，并逐小任务提交PR，详见[ADR0014](0014-defer-review-and-deliver-small-prs.md)。该决策仅替代本文代码审查的执行时点；人工测试继续暂停，原失败及数据/产物保护要求保留。
