# ADR 0011：学习事件、笔记关系与可重建投影

2026-10-29。按既有R1–R6开发授权实施；人工和阶段验收待统一进行。

复用0011不可变learning_events追加注记、复习事件、相关note_id及记录知识点修订，不更新Attempt、Review、QuestionVersion或MD。每次记录使用显式幂等键，同内容重试返回原事件；旧事件中null与省略按同一请求语义兼容。笔记只建立同空间稳定ID关系，最多100个不同笔记；笔记后续编辑显示当前内容，丢失保留关系并明确提示。它不是笔记快照。

作答时知识点取不可变确认版，旧无版本仍未知。记录标签投影为最后一条明确knowledge_points；[]为明确清除，省略/null为无修订。遍历完整事件流重建，与当前历史页无关，算法latest-explicit-annotation-v1。既有题目掌握/到期算法命名attempt-review-streak-v1，依赖实际作答和最新人工评分；自评、纠错标签及复习点击不直接加分、增加连击或覆盖待批改状态。复习次数单独从reviewed事件重算。无需持久化不可重建的“最后掌握值”。

普通业务离线，令牌/Origin、空间校验和图片保护不变。旧题目/原件/作答/失败证据保留，无新依赖，无子Agent，不替换发行包。事件与笔记关系不代表完整备份恢复；发行、普通用户/干净机及人工阶段边界继续保留。验证见[R5完成记录](../r5-completion-2026-10-29.md)。
