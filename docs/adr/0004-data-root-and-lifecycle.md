# ADR 0004：M1 数据位置、迁移与本地进程

现行关系（2026-10-30整理）：启动位置/配置定位由[ADR0006](0006-default-user-storage.md)替代；配置拒写普通启动降级见现行[打包指南](../packaging-windows.md)。迁移校验、锁和数据保留规则继续有效。

日期：2026-10-24。状态：采用。用户授权继续实现和自动测试 M1，并回测 M0；不以此代替人工或干净机验收。

首次启动选择数据目录；已有 M0 目录默认作为候选，不自动删除或搬走。启动配置位于用户 LocalAppData/StudyWorkbench/settings.json，由 Python 在数据库成功打开后原子写入。无效配置/不可写目录提供重新选择入口。测试通过编译参数隔离数据与配置。数据路径必须绝对、本地、非磁盘根目录，不能与安装目录互相包含；首次目录为空或含已有 study.db。

设置中的迁移先保存所有页面、卸载原生页面并等待环境释放、正常停止后端，再由独立 Python 工作进程迁移。旧目录始终保留；目标须为空且不能嵌套新旧路径；拒绝重解析点。逐文件 SHA256、复制前后源文件校验、SQLite backup/逻辑内容/integrity_check/foreign_key_check、目标应用启动检查均成功后才原子切换配置。失败保留目标现场，继续原配置；不自动清理任何个人资料。目录迁移不是跨卷原子 move。配置切换原子，不宣称整个目录复制原子。

普通后端、迁移工作进程持有数据目录与配置会话的 OS 文件锁；Windows 桌面另持有 Local\\StudyWorkbench.Desktop mutex，重复启动只尝试唤回已有窗口。SQLite 写业务使用 BEGIN IMMEDIATE，名称唯一性、至少一个活动空间、归档与当前选择检查在同一写事务内，防止并发请求绕过检查。

普通后端在父进程管道 EOF 后退出；GUI 检测意外退出，保留内存布局/草稿，重启后通过业务 API 重放页面状态。正常退出等待自动保存并关闭自有后端；失败取消退出。迁移工作进程也监测父管道，目录扫描、每1MiB文件哈希/复制块、每256页SQLite备份、逐行逻辑比对及配置切换前检查取消。阻塞的单次磁盘操作、SQLite完整性检查与目标应用校验仍须返回后响应，不保证硬性实时停止。连续迁移使用新的回执文件名，保留旧回执与其被复制文件的校验值。已提交作答只追加，未确认的写请求不自动重放。

发行构建改用签名已核对的独立 CPython 3.13.17 / PyInstaller onedir，冻结入口显式使用 UTF-8 管道。Inno 7.1.0 使用官方 portable 模式部署到项目忽略目录。构建工具与 WebView2 离线安装器固定 SHA256并核对发行者；微软 Evergreen URL 变化时哈希失配必须停下复核。VC++ CRT 采用本地 DLL 分发，收集 Python/Dart/Flutter/native 许可与文件哈希。安装器只包含应用文件，不包含个人数据库；卸载脚本无个人目录清理。

技术栈未改变，没有复制 Seal 代码或修改玻璃库/缓存。签名、实际安装/卸载、无 WebView2 的干净 Windows、原生焦点快捷键和真实显示器 DPI/性能继续单独验收；生成 setup 不能将这些项目改为通过。

最终审查增加真实 SQLite 读事务：workbench 的工作空间列表与当前选择来自同一快照，避免读取期间另一个请求新建空间导致活动 ID 不在列表。并发创建/移除与读取交错均有真实数据库回归，失败日志保留。

后台续测补充：本地盘校验调用Windows GetDriveTypeW拒绝映射网络盘。冻结退出诊断捕获Proactor连接重置回调WinError10054与循环等待栈；Windows后端改用标准库Selector循环，新增实际TCP RST后父EOF退出回归，仍限10秒。当前服务仅用本地TCP，stdin由线程读取；未来若引入asyncio Windows子进程/管道须重评兼容性。没有关闭异常检查或延长测试上限。证据见m1-background-2026-10-24.md。
