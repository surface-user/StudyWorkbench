# R4：题目Markdown与不可变确认版

## 本批范围与顺序

1. 冻结QuestionFile v1，与旧QuestionDocument v1、旧提取Markdown v1分别编号。UTF-8 Markdown包含稳定题目ID、类型/来源/知识点、相对附件、正文/选项/答案/解析和可选共享材料。复用现有块与评分模型；缺答案用显式null和填空ID，不编造标准答案。未知元数据保留，未知格式/块拒绝发布但保留原件。
2. 内容以MD文件为权威：文本/公式正文可直接编辑；复杂结构块用隐藏类型记录和可读投影保留全部字段，投影改动不一致时明确报错，不能忽略可见修改。普通Markdown仍可阅读题干、公式、图片/表格、选项、参考答案/解析及来源。首版不做无损通用Markdown AST或所见即所得排版。
3. 0010只追加question_files映射、question_versions确认收据和attempt可空version_id。旧行/历史版本号/分数/文件不改，旧记录不补造快照。确认版包含MD字节、编译内容、共享材料及附件hash/快照。应用接口不修改历史快照，数据库禁止更新/删除确认版。
4. 复用DocumentFiles原件/工作副本/expected hash/保存收据；打开/检查不升级。显式预览旧JSON或旧Markdown转换，确认后创建新可编辑文件和目录映射，旧原件/行/ID保留。ID冲突拒绝，不凭题干或标题合并。发布确认版是另一步，必须核对当前文件hash、预期确认版及附件hash。
5. 新文件只有确认后才进入练习缓存和提交；提交携带确认版ID、在服务器读取不可变内容判分，缺答案只验证作答形状并待批改。旧未映射JSON题目沿用原接口。重试按原request_id/答案/版本幂等，不因新发布版改旧作答。未确认修改不自动更新标准答案。
6. 资源文档页内提供检查/预览/确认/已确认作答，复用QuestionPreview和StudyAnswer。同标签身份不拆成新题库；草稿、页内模式/关闭行为同步校验。学习页双读当前确认版；导出带可独立阅读的当前MD与相对附件、确认版及状态，不假装完整恢复包。
7. 自动化：七类协议与全块往返、空答案、未知字段/格式、重复ID、来源降权、路径/附件/空间隔离、旧JSON/提取MD显式转换、外部修改/确认冲突、不可变版本/旧分数/幂等、0009升级/失败回滚/旧行文件；双Python、Flutter/Schema、真实Windows、Release编译和冻结专项分开记录，保留失败。
