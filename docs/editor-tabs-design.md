# Editor Tab Bar 实施设计（2026-10-25）

依据 docs/task.md 的 Tab UI Specification v1.0。本批仅改标签与页面宿主管理，不改业务数据模型或新增依赖。

1. EditorTabBar 承担 38px 连续标签、112–220px 有界宽度、图标/状态/关闭命中区、横向滚动、活动页定位、溢出列表、右键与开关动画。工具跟随短标签组，溢出时固定。减少动画遵循系统设置。
2. WorkspaceLayout 继续管理身份、顺序、关闭历史；活动页关闭优先左邻。侧栏学习/导入/媒体入口复用同类型唯一页面；显式新建允许独立页，网页不按显示标题去重。当前资源详情仍是业务页内的模态编辑/预览，没有虚构独立资源页或固定标签能力。
3. WorkspaceShell 统一快捷键与批量关闭。题目草稿与最后成功保存值比较，显示未保存点；保存/放弃/取消，失败不关闭。自动保存成功清点。布局请求不阻断标签交互，空间变更沿用原串行门禁。
4. 页面通过轻量状态回调报告加载/错误/网页标题。回调延迟到帧后写入，避免子页面初始化时重建祖先。页面先沿用惰性 IndexedStack；真实Windows发现当前Flutter的IndexedStack无Key包装导致关闭兄弟页重建，现改为PageHost（Stack直接子项以页ID为Key的Offstage、ExcludeFocus、TickerMode）；关闭立即释放页面，动画只保留标签外观。每空间16页，关闭历史10页。已访问空间仍保留，移除空间销毁。
5. WebView/播放器切换不重建，后台媒体沿用继续播放策略，关闭释放环境。重开恢复持久化草稿/URL/媒体库状态，不宣称恢复关闭前完整网页实例。笔记/真实练习编辑为模态窗口，操作期间不允许操作标签栏。

验证任务：布局/活动邻居与导航去重；组件动效/溢出/焦点/菜单/快捷键；草稿串行保存/确认/失败与页面实例；Windows真实窗口五类型页与WebView/播放器进度、截图；Flutter全量/静态检查/Release构建；记录命令、退出码与边界。用户人工/阶段验收统一待验。
