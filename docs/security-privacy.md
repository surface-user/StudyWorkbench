# 本地安全与隐私

## 当前已实现

外部网页、导入文档、下载地址与未来模型输出均不可信。同一Windows用户的恶意进程不属于会话令牌能完全抵御的攻击者，不承诺失陷账户保密。SQLite不默认加密。

后端loopback随机端口、强随机会话令牌、Host/Origin校验，无公开docs/openapi或全局CORS。令牌只stdin/内存流转，不打印/持久化。播放器capability与业务令牌分开、只绑定指定媒体，后端会话结束失效；有权读取profile的进程可能看到能力URL。

外部WebView不注册业务JS桥/主机对象，默认拒绝权限/新窗口；插件内部脚本不等于禁用。URL/DNS预检存在请求时序差，不构成DNS重绑定完整防护。可信播放器CSP隔离，外部页面不得取得文件或特权API。

受管复制验证本地路径、重解析点/网络盘/目录交叠、来源变化和预算；导入按类型检查扩展名/签名/MIME与内容，HTML仅提取文字。预检不证明格式完整有效。解析/渲染子进程、Office输入门禁/禁宏外链/独立profile/Job/超时限制已接入，不宣称完整OS文件/网络沙箱。

数据目录和安装分离，Known Folder按进程完整性定位；不提权或修改用户ACL绕过拒写。配置拒写降级保留可写数据与警告，迁移仍须配置提交。升级备份、失败保留旧库和文件；树删除不擦除学习数据，卸载默认保留。

位置标记已继承会话、空间、受管路径及版本校验；笔记关系不传递Agent权限。播放器原生控制仅在当前URL与指定loopback媒体player及cap精确匹配时读取时间/执行有界数值跳转，不注册JS业务桥、不向网页传业务令牌；外部页面无此控制。媒体时长只做有界容器元数据读取，不执行解码器。

内部链接仅原生UI识别v1 URI，点击才发受鉴权的固定resolve请求；单次解码、严格ID/段数校验，拒绝参数/片段/残留百分号/路径及控制字符。跨空间拒绝且不自动切换，移除或失效目标不猜测替代。复制/往返只存稳定目标及受限视图，不携业务令牌/播放器能力，不注册Windows协议或网页业务桥。外部HTTPS继续由隔离WebView处理。

备份包读取核心会先限制ZIP中央目录大小/实际条目数量，再使用标准库读取；严格JSON/相对路径/Windows名称与碰撞、只允许普通文件与Store/Deflate/ZIP64扩展，流式校验payload大小/hash。只读CLI不执行包内数据库、不解压/激活或修改配置；该检查命令不等同实际恢复或产品验收。

离线完整库备份/恢复已有本地实现：普通UI明确全部空间/归档范围与未加密隐私，先保留草稿并停服释放锁，再由固定参数子进程处理；无HTTP路径执行接口。目标只允许新空目录，实际流式字节/磁盘预算、受管原件及确认资产、SQLite完整性/FK/行摘要均校验后才原子提交外部启动配置；不改旧库，不覆盖外部新文件。失败保留字节/旧配置，成功只清理独占创建且已验证提升的暂存副本。排除实际WebView profile、运行锁/WAL，不恢复当前会话令牌/能力或内存grant；未知普通学习文件保留。恶意格式/断电/干净机与实际窗口矩阵仍待验证。

直接媒体下载已有本地公网IPv4/443直链实现：每跳DNS全部地址预检并固定连接地址，原域名TLS/SNI校验、无系统代理/cookies/业务令牌；工作子进程期限与取消、实际字节/强ETag/前缀hash及受管原件校验已接入。完整query只存个人库/未加密全库包，不在列表或普通错误返回；真实网络负面矩阵和来源/播放仍待验。

本地分析授权默认摘要，显式扩展才读取所选正文与历史确认版，读前/后复核、期限/预算与未知历史边界见API。候选统一外部来源/未验证，不执行候选文字；独立采用不暴露给模型工具，不改答案/评分。审核修订追加保留，失败不覆盖其他编辑；草稿包含学习引用，随个人库及未加密全库备份保留。当前无模型请求、下载或凭据。
