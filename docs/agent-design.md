2026-10-25方向修正；**目标设计，尚未接入模型/凭据或新增工具接口**。实施位于R6，先完成资源身份、题目文件与历史反向关联。本轮不把此前M5错题总结闭环当作唯一产品入口。

## 用户主动发起的能力

| 请求 | 模型负责 | 普通程序负责/确认点 |
|---|---|---|
| 阅读指定资料，识别候选题 | 语义边界/题型建议，表达不确定性 | 范围授权、受控读取、候选预览；修改/选择/确认后独立MD入库 |
| 分类与关联笔记 | 建议知识点、引用关系和理由 | 校验目标ID/空间、用户确认后保存元数据，不把建议当既定分类 |
| 指定集合生成练习计划 | 解释学习重点/计划建议 | 本地筛选/随机抽题、幂等保存和进度统计；计划可无LLM生成 |
| 阅读作答历史分析薄弱点 | 错因与薄弱知识点的语义总结 | 本地统计事实、授权指定记录，建议可修订；不由一次错误推断长期掌握 |
| 生成AI变式 | 候选题干/参考答案/解析 | 预览确认、格式与评分约束、原题ID和模型/时间来源；默认ai_generated/unverified |

## 拟议权限与接口边界

授权以workspace、显式资源/题目/attempt集合、用途和有效期为范围。远端提供方调用前说明出境内容，拒绝授权不影响离线功能。网页/文档内容都是不可信输入，不能扩大工具授权或触发隐含批量写入。

拟议工具仅包括`read_resources`、`read_attempts`、`create_question_draft`、`suggest_links`、`propose_plan`、`create_analysis_draft`、`propose_variant`等有限业务操作，名称不是已实现API。创建草稿不等于发布；确认在模型控制之外，由普通UI发起带摘要/版本及幂等键的提交。目录/题目ID由程序分配和校验。

模型不能任意shell、SQL、任意文件读取/删除、覆盖原件、直接修改标准答案或评分。修改用户确认答案必须走普通文件编辑/新版本发布，保留旧版本/旧作答。输出需协议、大小、附件归属及来源降权校验，保留拒绝和失败状态。

无模型、无密钥、断网或配额耗尽时，资源树、查看/编辑、确定性提取、抽题、作答和复习仍可用。凭据通过Windows安全凭据方案按需实施，不存普通SQLite、文件正文、网页或日志。

复用ImportJob/候选审核、题目协议、学习统计与受控保存；不另造Agent专属题库/文件系统。先运行确定性流程再引入语义辅助，验收不得以“模型返回文本”替代用户确认和真实MD/记录落盘。

## R6本地授权读取增量（2026-11-03）

当前已实现：学习页作答历史显式勾选1–100条记录、确认5分钟本地授权、另行读取摘要、撤销及撤销后关闭；失败保留以重试，过期404清除。API均继承既有Bearer/Host/Origin检查，每次校验空间及作答归属。

接口：POST `/api/workspaces/{workspace_id}/agent-grants` 接收严格独立正整数attempt_ids、purpose=analyze_attempts、expires_in_seconds=1–900（默认300）、严格confirm=true，拒绝额外字段；返回id/范围/用途/期限和transport=local_only。DELETE `/{id}` 撤销；POST `/{id}/read-attempts` 仅返回id/question_id/question_version_id/status/score/created_at。未知/跨空间/过期授权404；活动授权全进程最多100份，超限429。授权仅内存，单调时钟过期、重启失效，不新增表/迁移；撤销与读取串行。原始分数不含后续人工修订，不能用于完整学情判断。

规划中：模型/凭据、资源正文、单独远端授权、草稿外置审核和来源校验；本批不联网或修改学习记录。待验证：真实窗口结果及PR状态见[本任务报告](../dev/records/2026-11-03-r6-agent-access/report.md)，模型/完整R6和产品人工/阶段验收继续保留。上述当前实现取代本文件此前涉及R6全部未实施的描述；不改其他历史阶段结论。本PR以未合并PR #2分支为基线，代码/自动化/自审完成后仍需本切片computer-use验收才创建PR，不授权合并或发布。
