### 用户主动发起的能力

| 请求 | 模型负责 | 普通程序负责/确认点 |
|---|---|---|
| 阅读指定资料，识别候选题 | 语义边界/题型建议，表达不确定性 | 范围授权、受控读取、候选预览；修改/选择/确认后独立MD入库 |
| 分类与关联笔记 | 建议知识点、引用关系和理由 | 校验目标ID/空间、用户确认后保存元数据，不把建议当既定分类 |
| 指定集合生成练习计划 | 解释学习重点/计划建议 | 本地筛选/随机抽题、幂等保存和进度统计；计划可无LLM生成 |
| 阅读作答历史分析薄弱点 | 错因与薄弱知识点的语义总结 | 本地统计事实、授权指定记录，建议可修订；不由一次错误推断长期掌握 |
| 生成AI变式 | 候选题干/参考答案/解析 | 预览确认、格式与评分约束、原题ID和模型/时间来源；默认ai_generated/unverified |

### 拟议权限与接口边界

授权以workspace、显式资源/题目/attempt集合、用途和有效期为范围。远端提供方调用前说明出境内容，拒绝授权不影响离线功能。网页/文档内容都是不可信输入，不能扩大工具授权或触发隐含批量写入。

拟议工具仅包括`read_resources`、`read_attempts`、`create_question_draft`、`suggest_links`、`propose_plan`、`create_analysis_draft`、`propose_variant`等有限业务操作，API仅实现明确列出的作答摘要/分析上下文及普通用户候选审核路由；这些拟议工具名称不能直接调用。创建草稿不等于发布；确认在模型控制之外，由普通UI发起带摘要/版本及幂等键的提交。目录/题目ID由程序分配和校验。

模型不能任意shell、SQL、任意文件读取/删除、覆盖原件、直接修改标准答案或评分。修改用户确认答案必须走普通文件编辑/新版本发布，保留旧版本/旧作答。输出需协议、大小、附件归属及来源降权校验，保留拒绝和失败状态。

无模型、无密钥、断网或配额耗尽时，资源树、查看/编辑、确定性提取、抽题、作答和复习仍可用。凭据通过Windows安全凭据方案按需实施，不存普通SQLite、文件正文、网页或日志。

复用ImportJob/候选审核、题目协议、学习统计与受控保存；不另造Agent专属题库/文件系统。先运行确定性流程再引入语义辅助，验收不得以“模型返回文本”替代用户确认和真实MD/记录落盘。

## 本地授权及人工候选边界

用途仅analyze_attempts、显式1–100个同空间作答ID、严格confirm=true，1–900秒（默认300），至多100份活动授权；授权仅进程内存、重启失效，不落库。撤销与读取串行，读前/后复核空间/到期。默认只返回原始作答摘要；另行勾选include_content才读取所选正文与当时确认版，不含二进制附件、最新人工评分、事件或笔记。历史未知不猜当前版本，预算及字段见API，不能据此声称完整薄弱点分析。

普通UI可手工录入外部候选，固定未经验证、引用及上下文hash；候选与审核修订持久保存，撤销授权不删除已保存内容。编辑/拒绝/采用绑定修订与内容hash，采用由普通UI另行确认，仅新建独立MD，失败保留收据/笔记而不覆盖其他编辑。失败候选可拒绝并停止重试，笔记和历史保留。模型没有采用工具；本流程无模型调用、下载、凭据或远端传输。

通用资源读取、模型/凭据与远端授权、其他候选场景仍规划中，不开放任意工具执行。原切片和既有交付义务见[原报告](../dev/records/2026-11-03-r6-agent-access/report.md)；新增授权/审核实现与验证见[报告](../dev/records/2026-11-05-lw08-authorization-review/report.md)，完整任务状态只在task维护。

### 授权与审核界面

学习页从已加载历史显式勾选范围，确认5分钟本地授权；默认读摘要，正文选项须另勾选。授权ID仅弹窗内存，关闭先撤销，失败保留以重试，失效404回到重新确认；授权期间不绕过撤销关闭。候选列表独立于临时授权，可查看/编辑待审候选、审核修订、拒绝或单独确认采用；已建笔记打开前重验状态。退出/备份/迁移先刷新编辑器，保存失败保留文字并取消退出；明确放弃只关闭窗口，不删除服务器可能已经保存的候选。实际窗口与用户验收仍待完成。
