# 产品需求：以文件与学习资源为核心

现行验证安排：用户2026-11-06已取消人工测试及Computer Use/实际窗口测试，不再作为开发或退出门禁；历史未验不补记通过。自动化、代码审查及当前head CI继续，产品内用户授权/候选审核确认保留，详见[ADR0013](adr/0013-cancel-manual-testing-and-bound-artifacts.md)。

StudyWorkbench是Windows本地优先个人学习工作台。核心对象为工作空间、文件夹、文件/链接资源和追加学习记录。题库、复习、统计和可选Agent建立在这些对象之上。408、数学、英语、政治可作为用户自定义分类，不作为导航和模型的硬编码边界。

本文件规定目标行为；[任务](task.md)记录实现与验收状态，[架构](architecture.md)区分当前能力和规划，详细交付过程见[开发记录](../dev/README.md)。

## 已采纳的普通学习体验方向（目标与实施边界）

面向各类学习者；无Agent、无模型、无密钥时，也应独立完成资料阅读、媒体学习和自由笔记。后续补充可自行创建的笔记、多个位置书签与备注、跨资料/笔记的内部超链接和集中查找；不要求先拆题或作答。资料内容变化后明确提示位置是否有效，树内改名移动保持关系。

扩展主要学习格式和视频获取到本地下载；每种格式分别确定留存/查看/标注/编辑/Agent可读等级，不承诺所有格式无损查看编辑。新增记录纳入完整备份恢复；Agent复用授权资料与学习记录，支持既有题目分析并按确认范围扩展。范围、优先级及设计未定项见[学习工作台路线](learning-workbench-roadmap.md)。这是目标需求，具体实现边界以架构与任务表为准，不能据此把表格查看/下载/模型能力登记为当前已实现。

普通学习流程采用[契约](learning-workbench-contracts.md)：自由笔记复用MD工作副本、旧富内容笔记保持原权威；位置书签/备注、笔记来源关联及内部链接已有实现，集中查找与离线完整库备份/新空目录恢复已有本地实现，人工及发行验证仍待完成。资料页新建/选择笔记后须明确来源关联结果，失败保留笔记；页码/原文行/媒体时间点回跳必须验证版本，不能把预览滚动猜成原文位置。人工及用户文档复核保持待验。

## 工作空间与资源

- 导航为工作空间列表、新建、资源管理器/添加、学习和底部设置；资料处理与媒体视图由资源管理器菜单进入，兼容旧utility布局。
- 受管复制导入保留源目录和层级。预检、暂存、确认复制与内容提取是分开的步骤；取消确认前不创建复制任务。原生多选/OLE拖放共用清单，去重、移除、清空、部分失败和重试均有明确结果。
- 树内改名/移动保持节点ID；同空间资源可按名称搜索。删除须确认，文件夹包含后代；当前语义为从树中移除，原件、工作副本、学习记录保留，重启不复活，不承诺释放磁盘或回收站界面。
- 资源标签以稳定ID去重，同名/同hash不同逻辑资源不合并；切换保留状态，关闭脏文件确认，保存失败保留草稿。旧布局、未知标签和既有草稿保持兼容。
- 外部目录原地工作区、监听、站点提取/转码和永久擦除不属于当前已实现能力。

## 内容查看与处理

| 类型 | 要求与能力边界 |
|---|---|
| Markdown | 显式创建工作副本后编辑；原文/受控预览切换，冲突不覆盖原件 |
| UTF-8文本 | TXT只读原文/原文行；JSON/CSV/LOG/VTT/SRT只读原文/资源级书签，≤1MiB、坏编码明确拒绝、不执行内容 |
| XLSX | 常见OOXML多表只读单元格列表/资源级书签；公式缓存可能过期、缺失明确提示，不执行宏/公式，不承诺样式/日期格式/合并布局保真；预算及不支持输入见契约 |
| PDF | 分页、缩放、位置恢复；阅读预算与拆题预算区分 |
| DOCX | 结构预览；有可选离线转换组件时提供派生PDF |
| PPTX | 依赖可选离线组件生成静态派生PDF，不承诺动画/嵌入视频 |
| 图片 | PNG/JPEG查看与缩放，其他格式逐项设计验证 |
| 网页 | 隔离WebView2、导航失败反馈及系统浏览器回退 |
| 媒体 | MP4/WebM/M4A资源与播放器；续播/倍速/WebVTT字幕，编码支持需实际验证 |

原件保留，派生输出可追溯，不自动上传云端。未知格式可留存但明确查看限制；旧DOC/PPT、危险动态Office内容拒绝转换。内容处理可复用已有原件，先预览、用户确认后生成题目/笔记；不能自动猜测标准答案。OCR、多栏/复杂题号及更大文档处理仍列后续任务。

## 题目文件与学习记录

一题一个带稳定ID和格式版本的UTF-8 Markdown，相对附件可随文件携带。旧提取MD、旧JSON和QuestionFile分别兼容；升级须预览、显式创建可编辑副本并另行发布确认版。主观/缺答案题默认待批改，AI内容标注来源与验证状态。

当前MD/工作副本是编辑权威，已确认不可变快照是判分权威。改题或改答案不重判旧作答；作答和评分修订追加保存，旧无快照记录保持版本未知。记录可查看当时快照，打开当前题目/来源、显式关联笔记，追加错因、自评、知识点修订和复习事件；注记不修改标准答案或旧分数，投影可重建。

现有资源导出可携QuestionFile当前MD、相对附件和确认版，但不是包含全部学习历史的完整恢复包；自由笔记只导出初始原件，尚不携当前MD工作副本、位置书签/备注/修订及其关系，完整学习库保护由独立LW-05整库包/恢复承接，不能拿资源export替代。

## 可选Agent与离线要求

首批按用户要求先完善显式授权与外置人工候选审核，暂不接模型。R6后续只在授权范围内读取资源/记录、提出候选题、关联、计划、分析或变式草稿。确认由普通程序与用户执行，模型不直接操作SQL、任意命令、删除数据或修改标准答案。远端传输须明确授权；无模型、无密钥、断网仍可完成普通业务。详见[Agent设计](agent-design.md)。

## 数据与交付

技术栈固定Flutter/Dart、自有固定提交玻璃库、Python/FastAPI、SQLite/SQLAlchemy/Alembic、WebView2/HTML5。UI不直连数据库，后端仅loopback随机端口、令牌鉴权与Origin拒绝，不向网页暴露业务令牌/主机桥。

安装与数据分离，首次使用默认用户位置，已有配置/旧库优先；失败不得切换空库冒充恢复。迁移备份、校验、失败回滚和旧数据保留，卸载默认保留个人数据。安装器、普通用户/干净机、硬件及阶段验收与自动化证据分别记录，不因功能存在或代码提交而销项。
