# 站点双轨来源与恢复

0023 在既有下载任务和执行记录上保存已确认的双轨来源、实际收到的两份文件及合成输出。来源限定于固定提取器、组件和配方。数据库约束保持来源不可变，同一个空间的同一预览最多建立一项双轨任务。个人库备份和完整性检查逐一核对已收到的文件、实际大小与哈希。短期预览仍按原规则过期，恢复时不会取得网络执行授权。

含既有合成执行记录的 0022 库首次升级失败。SQLite 在替换父表时阻止了外键悬空。迁移现使用同一事务的临时表保存旧执行行，父表与原索引重建后按原值恢复。测试中途注入错误后，0022 的全部业务表与迁移前一致，继续升级与独立恢复旧整库备份也保留了所有业务行。原件和归档原样保留。

`python -m pytest -q backend/tests/test_media_sources.py` 中的迁移、站点来源、备份与恢复用例覆盖已提交、已取得轨道和输出移动待提交的情形，以及重复预览、大小、哈希、路径、来源变化、丢失文件和总额度。旧合成任务仍按原机制校验本地源。来源、收据和文件均使用本机生成的测试数据。Ruff 与差异格式检查退出 0。

本项交付数据库、读取和恢复能力。经站点重新核对后受控传输两条轨道并发布媒体由后续独立变更接入。真实站点下载仍待验证。

跨模块回归覆盖本次变更涉及的测试文件、既有双轨合成、站点选择和整库恢复。使用项目固定解释器分别执行 `python -m pytest -q <受影响用例> --basetemp <专用目录>`。Python 3.12.7 通过 340 项，另行补跑最后加入的同预览唯一索引用例。Python 3.13.17 通过全部 341 项。初次受限环境的 Windows 联接创建失败保留，使用获准的独立测试目录执行上述回归。
