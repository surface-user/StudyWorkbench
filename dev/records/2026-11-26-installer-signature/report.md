# REL-04b Windows 安装器验签

基础安装器的外层 EXE 已有独立核验入口。读取固定成品名，用调用方提供的 SHA256 锁定文件与签名者，核对 Windows 对内嵌签名的信任状态和时间戳证书。保留旧的冻结后端命令与收据字段。操作方法见[打包说明](../../../docs/packaging-windows.md)。

- 两个 Python 版本分别运行 `python -m pytest -q backend/tests/test_backend_signature.py`，各 4 项通过，退出 0。使用 Windows SDK 已签名样本核验正常路径，将文件变动及错误签名者作为负例。仅有后端文件的目录无法产生安装器收据。
- 实际基础测试安装器大小为 278,410,830 字节。先与构建记录中的成品摘要比对，再调用安装器核验入口。Windows 返回 `NotSigned`，命令拒绝输出成功收据。预期失败断言退出 0，检查期间只读成品。
- Ruff 与 Git 空白检查均退出 0。可信发行身份、实际签署和正式发行仍待具备相应条件。
