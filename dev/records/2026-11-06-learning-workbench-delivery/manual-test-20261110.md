# 2026-11-10 用户人工测试清单与汇报模板

本轮由用户主动要求并亲自执行，结果待用户汇报。此安排仅覆盖本次本地Release交付，不恢复所有任务的人工测试门禁，不把历史取消记为通过。Agent不执行窗口验收，不接模型，不合并或公开发行。

## 开始前

- 产品代码基线：PR #18，2a884fe4f665b3ce50152914e32ee60314af60c9；版本号1.0.0+1。构建运行、文件SHA256和包路径以交付目录build-info.json为准。
- 安装入口为交付目录中的setup.exe；免安装入口为app/study_workbench.exe。保留app整目录，不单独挪走exe。安装版和免安装版先选一个测试，切换前正常退出。
- 正常版本会使用已配置的数据位置；已有学习数据先备份。建议新建“人工测试”工作空间，用副本或附带自编样本，不故意损坏原库。先记录设置页显示的数据位置。
- 每项填写“通过 / 失败 / 未测”，未测不算失败或通过；先做A组，再按需要做B/C组。不要为了测试手动删除个人数据、修改数据库或清除缓存。
