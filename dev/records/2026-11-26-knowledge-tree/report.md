# 科目内的知识点树

M3-03b2b 的目录树部分基于 [科目后端 #112](https://github.com/surface-user/StudyWorkbench/pull/112)。通过受控接口逐层查看、创建、改名、移动和移除知识点，按稳定 ID 回读历史。科目和知识点共用空间内请求键。已有子项时拒绝移除，两次并发反向移动只能成功一次。资料、题目和知识点之间的显式关联另行交付。

数据库从 0019 升级为 0020。新表初始为空，保留既有科目、旧作答及原文件。归档恢复先核对活动目录、父子引用和修订，再切换设置。使用具有完整外键但含循环的归档，实测备份和恢复都拒绝，原设置字节保持。

- 以分支锁定的 Python 3.12、3.13 分别运行 `python -m pytest`，范围为包含当前或未来迁移版本断言的后端测试及学习记录测试，每版 293 项通过，退出 0。最初的损坏库夹具误用只读连接，随后用于恢复的配置又不是有效 JSON。两次失败均保留，改为可写测试副本和正常配置后重跑，循环拒绝和配置保留断言通过。
- `ruff check backend tools`、`python tools/export_question_schema.py --check` 和 `git diff --check` 均退出 0。
- `packaging/windows/build-backend.ps1` 产生 Windows 后端，52 个冻结模块与当前源码相符。实际 0019 程序先建科目和作答，0020 程序启动后建立升级前备份，通过 HTTP 创建两级知识点、拒绝环、移动、重试及回读历史。通过冻结程序的离线备份和恢复入口建立副本，原库和恢复库重启后保有相同历史及作答。退出 0。

冻结程序沿用 #112 的依赖，仅用于此功能验证。审查暂缓，人工测试已取消。完整数据库、输入与运行日志保留本机。
