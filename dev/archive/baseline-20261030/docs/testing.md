# 质量与验收

自动化：pytest（鉴权、Origin/Host、客观/主观评分、追加持久化、非法响应、媒体 Range、Alembic）；Ruff；Flutter analyze/test（公式与导航、URL 安全规则）；Windows release 构建。CI 运行这些检查并上传结果；工作流文件存在不等于远程 CI 运行成功。

人工 M0：按 README 启动 Windows 原型，无模型密钥；检查玻璃/公式；提交客观正确、错误、主观答案；切换标签并观察状态；重启验证数据库；外部网页导航/刷新/系统浏览器；加载自有 MP4/WebM，检查播放/暂停/跳转/倍速/字幕/续播；测试缺 Runtime/不兼容编码错误。记录 OS、Runtime、样本编码、截图和结果。

M1：工作空间隔离和重启恢复；数据目录故障迁移/回滚；setup 自选路径/无 Python 干净机启动/卸载保留。
M2：DOCX/PDF/HTML/MD 每类正常/损坏/公式/表格/图片样本，预览确认/重复/保留原件；富内容附件边界。
M3：各科题型、组卷、主观待批改、错题追踪、掌握度/到期复习和统计一致性。
M4：授权 URL 下载取消/断网/重试/恢复、格式失败、字幕/续播；WebView 安全负面测试。
M5：AI 授权、无 API 降级、输出校验、确认保存、变式验证标签。

失败证据保留，不能删除测试或缩小测试后把局部通过写成全部通过。
